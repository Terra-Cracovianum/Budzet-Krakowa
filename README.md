# Budżet Krakowa

Plan budżetu Miasta Krakowa na lata 2016–2026 według pierwotnych uchwał Rady Miasta Krakowa, oraz wykonanie i absolutorium dla lat, które Rada już zamknęła.

Strona jest statyczna: `index.html`, `style.css`, `app.js` i pliki w `data/`. Kwoty są w złotych. Rejestr dokumentów jest w [sources.md](sources.md).

Parser uchwał: `scripts/extract_budget.py`. Odczyt opinii Komisji Rewizyjnej: `scripts/extract_wykonanie.py`. Składanie plików JSON: `scripts/build_data.py`.
